| 制度 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/auth/login` | 登录并获取 JWT |
| GET | `/api/admin/dashboard` | 数据责任域运营数据 |
| GET | `/api/admin/work-orders` | 质量任务清单 |
| GET | `/api/shopfloor/dashboard` | 工程师任务工作台 |
| POST | `/api/shopfloor/work-orders/{id}/reports` | 提交质量整改结果 |
| POST | `/api/admin/quality-score` | 数据集质量评分 |
